# |VOID|

I build software, reverse-engineer hardware, and automate things that shouldn't need a human to babysit them.

Usually it starts with something that's locked down, poorly documented, unnecessarily dependent on somebody else's server, or just irritating enough that I want to understand it.

I work across Linux, Android, embedded systems, protocols, and process automation. I don't particularly care which layer the problem lives in.

## Some things I've built

- **[iCSee Local Control](https://github.com/voidnullvalue/Icsee-android)** — An Android app that talks directly to iCSee/Xiongmai cameras over their native protocols. No vendor cloud account required.
- **[SnuSnuRoot](https://github.com/voidnullvalue/SnuSnuRoot)** — A rooting and Magisk bootstrap toolkit for a Fire HD 10, built around a device-specific exploit chain.
- **[ReBox](https://github.com/voidnullvalue/ReBox)** — A replacement native media shell for the DIRECTV HR54-700, using the hardware's existing Linux and media stack. Still early alpha.
- **[InfiniWolf](https://github.com/voidnullvalue/InfiniWolf)** — Procedurally generated Wolfenstein 3D campaigns, with coherent layouts, progression, and encounters rather than random rooms glued together.
- **[Synergize](https://github.com/voidnullvalue/synergize)** — A real programming language interpreter written in corporate management-speak. Unfortunately, it works.
- **[ESP32 Weather & Radar Panel](https://github.com/voidnullvalue/ESP32-S3-4848S040-480x480)** — A standalone touchscreen forecast and animated radar display using ESPHome and LVGL. No always-on backend.
